# Meta-Wallet

Landing page with MetaMask wallet integration — connect your wallet, view ETH and USDT balances on Ethereum Mainnet.

** [Live Demo →](https://tanykos.github.io/meta-wallet/)**

## ✨ Features

- Connect / disconnect MetaMask wallet
- Display ETH balance on Ethereum Mainnet
- Display USDT balance on Ethereum Mainnet
- Network validation (Mainnet only)
- Copy wallet address with visual feedback
- Offline detection banner
- Responsive design with mobile-optimized images

## 🎨 Tech Stack

- **React 19** + **TypeScript 5.9** (strict mode)
- **Vite 7** (bundler)
- **Tailwind CSS 4** (styling)
- **ethers.js 6** (Web3)

## Getting Started

### Prerequisites

- Node.js 18+
- MetaMask browser extension

### Installation

```bash
git clone https://github.com/tanykos/meta-wallet.git
cd meta-wallet
npm install
```

### Environment

Copy `.env.example` to `.env`:

```bash
cp .env.example .env
```

### Start development server

```bash
npm run dev
```
